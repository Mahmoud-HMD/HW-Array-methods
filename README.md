# Лаборатория методов массива

Учебное задание: мутирующие и немутирующие методы массива в React. Полный текст задачи — в файле [array-methods-task.md](./array-methods-task.md).

## Как запустить

Нужен [Node.js](https://nodejs.org) версии 20.19 или новее. Проверить: `node -v`.

Открой терминал и выполни по порядку:

```bash
cd ~/Desktop/array-methods-task
npm install
npm run dev
```

- `npm install` — ставит зависимости, делается **один раз**. Появится папка `node_modules`, она в проект не входит.
- `npm run dev` — запускает сайт на `http://localhost:3000`, браузер откроется сам. Если нет — открой адрес вручную.

Страница сама перезагружается, когда правишь файлы в `src`.

Остановить сервер: `Ctrl + C` в терминале.

### Если что-то пошло не так

| Проблема | Что делать |
|---|---|
| `command not found: npm` | не установлен Node.js, поставь с [nodejs.org](https://nodejs.org) |
| `Port 3000 is in use` | порт занят, Vite предложит другой — нажми Enter |
| Белый экран | открой консоль браузера (F12 → Console) и смотри ошибку |
| Список пустой | проверь, что берёшь персонажей из `data.results`, а не из `data` |

### Другие команды

| Команда | Что делает |
|---|---|
| `npm run build` | собирает готовую версию в папку `dist` |
| `npm run preview` | показывает собранную версию |

## Коротко о задаче

На экране список персонажей с [Rick and Morty API](https://rickandmortyapi.com/documentation) и 10 кнопок — по одной на каждый метод массива.

| Мутируют | Не мутируют |
|---|---|
| `push`, `pop`, `splice`, `sort`, `reverse` | `map`, `filter`, `slice`, `concat`, `join` |

Правила:

1. Исходные 20 персонажей лежат в state `original` и **не меняются никогда**.
2. Мутирующие методы вызывать **только на копии**: `const copy = [...characters]`.
3. В шапке видно `Исходных: 20 · Сейчас: N`. Если число «Исходных» изменилось — где-то произошла мутация, это баг.

Главная проверка: нажать `sort`, потом «Сбросить». Исходный порядок обязан вернуться.

Остальное — требования, чек-лист, подсказки и бонусы — в `array-methods-task.md`.
